## O que é este arquivo

Este documento é a **fonte de verdade** do Simulador de Produção. Ele contém o
mapa completo das 9 fases, o caminho dos dados pelo sistema e as paradas de
teste de cada fase.

## Como ele é usado

- **Toda fase começa aqui.** Antes de escrever código de uma fase, este
  documento é lido para confirmar objetivo, escopo e critério de aceite.
- **Em caso de conflito, este arquivo ganha.** Se o código, um comentário ou
  uma conversa divergirem do plano, o plano está certo até ser explicitamente
  alterado aqui.
- **Alterações no plano são alterações de escopo.** Mudar algo neste arquivo
  pede também um registro em [`docs/decisoes/`](./decisoes/) explicando o
  porquê.
- **Ele não é log de execução.** O que foi efetivamente feito em cada fase fica
  em [`docs/fases/`](./fases/).
