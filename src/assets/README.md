# src/assets

Identidade institucional do projeto: logos, ícones SVG, fotos de capa e
qualquer imagem importada pelo código React (`import logo from '@/assets/...'`).

Arquivos aqui passam pelo build do Vite — recebem hash no nome e são
otimizados. Para arquivos que precisam de URL fixa e previsível
(ex.: `favicon.svg`, `robots.txt`), use a pasta `public/` na raiz.

Vazio na Fase 0.
